# Symbio Skin Library

PCL Symbio Edition 的现代化 WPF 界面原型和组件系统。

## 特性

- 🎨 现代化界面设计：实例墙、资源市场、活动管理
- 🌓 动态主题系统：浅色/深色/跟随系统，三种强调色预设
- 🧩 可复用控件库：SeButton、SeCard、SeToggle 等 WPF 控件
- ⌨️ 完整键盘支持：Ctrl+K 命令入口、方向键导航
- ♿ 无障碍兼容：高对比度模式、屏幕阅读器支持
- 📐 DPI 适配：100%～200% 缩放自动适配

## 快速开始

```powershell
git clone https://github.com/yourusername/Symbio-Skin-Library.git
cd Symbio-Skin-Library
dotnet run --project .\PclSe.Fluent.csproj
```
